Def Jam: Icon

Def Jam, EA Chicago · 2007 · Combat, musique

  • Sur PS3, Xbox 360
  • 73/100, moyenne de 21 notes de joueurs et de critiques (IGDB)

Def Jam: Icon est un jeu vidéo de combat mettant en scène des rappeurs américains tels que Lil Jon, Paul Wall, Bun B ou T.I.. Les décors peuvent alors devenir avantageux ou désavantageux pour le joueur. Def Jam Icon est doté d'un gameplay moins dynamique dans les combats que dans les précédents opus.
