Alundra 2: A New Legend Begins

Matrix Software · 1999 · RPG

  • Sur PS1
  • Histoire : ~14 h, avec les à-côtés : ~18 h, tout faire : ~25 h
  • 59/100, moyenne de 16 notes de joueurs et de critiques (IGDB)

Alundra 2 : Une Légende est née, ou simplement Alundra 2, est un jeu vidéo de type action-RPG. Suite du très apprécié Alundra, ce volet n'a aucun rapport avec le premier opus, si ce n'est bien sûr le nom du jeu, leur police de caractères, leur compositeur, leurs éléments graphiques, deux couples de jeunes héros et bien sûr leurs énigmes corsées, avec même, dans le dernier donjon de chaque jeu, une énigme demandant de sauter sur des parallélépipèdes disparaissant en une seconde, afin d'enclencher un interrupteur permettant de terminer l'aventure.
